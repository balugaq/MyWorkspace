# 我的全能工作台（My Omnipotent Workspace）

一个集 **思维导图式 Todo**、**分类笔记** 与 **日历日程** 于一体的个人工作台。纯前端应用，数据保存在浏览器本地（localStorage），无需注册、无需服务器账号，开箱即用。

---

## ✨ 功能一览

- **分类导航**：内置模板（小说 / 学习 / 工作 / 生活 / 关系）+ 自由创建分类，支持重命名、删除、展开/折叠层级。
- **小说类 / 通用分类**：自动编号章节目录（命名规则可自定义，如「第__章」），每篇支持标题、正文、标签，可标记完成、上/下篇切换。
- **关系类（思维导图）**：在 React Flow 画布上用节点管理 Todo，节点间建立 **原因 / 导向 / 结果** 关系、附加子任务，可为节点添加 **解决方案**（绿色连线，状态 ●正在做 / ○暂停 / ✓已完成）。支持思维导图 / 列表双视图。
- **日历**：月 / 周 / 日三视图，有内容的日子用圆点标记；点选某天可编辑当日笔记、勾选待办、安排事件。
- **全局搜索**：跨「分类 / 篇目 / Todo / 解决方案 / 日历笔记」实时搜索，命中高亮，点击直达对应位置；支持范围筛选。
- **底部状态栏**：实时显示当前分类/日历的统计（共 N 项 / 已完成 X / 进行中 Y 等）。
- **系统设置**：默认启动视图、主题（浅色 / 深色 / 跟随系统）、自定义全局快捷键。
- **数据备份**：一键导出 / 导入 JSON，随时搬家或存档。

## 🚀 启动与本地部署

环境要求：Node.js ≥ 20。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（带热更新）
npm run dev
# → 打开 http://localhost:3000
```

**生产部署（纯静态站点）**，二选一：

```bash
# 方式一：一键「构建 + 本地静态托管」
npm run deploy:local   # → http://127.0.0.1:3000

# 方式二：分开执行
npm run build          # 产出 out/ 静态目录
npm run serve          # 静态托管；改端口：npm run serve -- 8080
```

`out/` 是完整的静态站点，可拷贝到任意静态服务器或对象存储直接访问。

> 说明：本项目为纯前端静态应用（`next.config.ts` 已启用 `output: "export"`），因此内存备份、数据均存于浏览器 localStorage；不兼容 `next start` 服务端方式运行。

## 📖 快速上手（分步骤引导）

### 1. 浏览示例与分类导航

- 左侧边栏「我的分类」下列出全部分类；点击分类名进入对应工作区。
- 点击分类右侧的 `⋯` 菜单可 **打开 / 重命名 / 删除** 分类。
- 「内置模板」区可一键快速创建新分类（点击即建并激活）。

### 2. 创建自己的分类

- 点击侧边栏「**+ 添加分类**」（或按 <kbd>Ctrl</kbd>+<kbd>N</kbd>）。
- 填写名称，选择模板：
  - **小说类**：自动生成编号篇目，可配置命名规则 / 自动编号 / 初始数量。
  - **学习 / 工作 / 生活**：空白条目分类，自由添加笔记。
  - **关系类**：空白思维导图画布。
  - **自定义**：空白分类。

### 3. 写一篇笔记（以小说类为例）

1. 侧边栏展开分类，点击某篇（如「静夜思」）。
2. 在右侧编辑 **标题**、**正文**，可给篇目加 **标签**。
3. 勾选右上角「完成」，底部状态栏的「已完成」计数会随之更新。
4. 用底部「上一首 / 下一首」在篇目间跳转。

### 4. 使用思维导图（关系类）

1. 打开一个关系类分类，进入颜色画布。
2. 点击右「**添加节点**」新建 Todo 节点，双击/点击节点在右侧面板编辑：
   - **原因 / 导向 / 结果**：描述节点间因果与去向。
   - **解决方案**：填写内容后会有 **绿色连线/节点** 展示，并可设状态（●正在做 / ○暂停 / ✓已完成）。
3. 拖拽节点底部圆点可与另一节点**连线**；点击连线可删除。
4. 右上角可切换 **思维导图 / 列表** 视图。

### 5. 记录日程

1. 点击侧边栏「**日历**」（或按 <kbd>Ctrl</kbd>+<kbd>B</kbd>）。
2. 用「< >」「今天」或顶部月/周/日切换查看。
3. 点击某一天 → 右侧面板编辑：
   - **今日笔记**：随手记录当天总结。
   - **待办事项**：回车添加，点复选框勾选完成，鼠标悬停可删除。
   - **事件安排**：填写时间 + 内容后添加。

### 6. 搜索内容

- 顶栏搜索框（或按 <kbd>Ctrl</kbd>+<kbd>K</kbd>）打开全局搜索。
- 输入关键词即可实时命中，可用「全部 / 当前分类 / 日历笔记 / Todo / 思维导图」筛选范围。
- 点击结果自动跳转到对应位置。

### 7. 个性化设置与备份

- 顶栏齿轮按钮打开「**设置**」：
  - **默认视图**：启动时进入工作台还是日历。
  - **主题**：浅色 / 深色 / 跟随系统。
  - **快捷键**：修改 / 重置「新建分类」「打开日历」「全局搜索」的组合键。
  - **数据备份**：导出 JSON 存档，或导入 JSON 恢复（导入会覆盖现有数据，请先导出）。

## ⌨️ 全局快捷键

| 动作 | 默认 | 说明 |
| --- | --- | --- |
| 打开全局搜索 | <kbd>Ctrl</kbd>+<kbd>K</kbd> | 搜索全部内容 |
| 新建分类 | <kbd>Ctrl</kbd>+<kbd>M</kbd> | 打开「添加分类」弹窗 |
| 打开日历 | <kbd>Ctrl</kbd>+<kbd>B</kbd> | 切换到日历视图 |
| 切换主题 | 按 <kbd>d</kbd>（无修饰键） | 浅色 / 深色切换 |

> 快捷键组合可在「设置 → 快捷键」中自定义。在输入框内打字时不会触发全局快捷键。

## 💾 数据与备份

- 数据全部保存在**浏览器 localStorage**（键 `my-omni-workspace`），清除浏览器数据会导致内容丢失，请定期导出备份。
- 建议：更换设备 / 浏览器前，在「设置 → 数据备份」**导出 JSON**；新设备导入即可恢复。
- 备份 JSON 含全部分类、日历、系统设置。
