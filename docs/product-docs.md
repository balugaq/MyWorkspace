# 我的全能工作台 · 产品使用指南

「我的全能工作台」是一个集**分类笔记（小说/学习/工作/生活）**、**思维导图式 Todo** 与**日历日程**于一体的个人工作台。数据保存在浏览器本地（localStorage），无需注册与联网。

## 1. 快速开始

- 启动后左侧是**侧边栏**，中部是**主工作区**，底部是**状态栏**。
- 已内置两个示例：**糖诗三百首收录**（小说类）与 **项目思维图**（关系类），用于快速上手。
- 最常用的几个入口：
  - 「**内置模板**」区：一键新建一个分类。
  - 「**+ 添加分类**」按钮：自定义创建。
  - 顶栏搜索框（或 <kbd>Ctrl</kbd>+<kbd>K</kbd>）：全局搜索。
  - 顶栏齿轮：设置与日历脚本。

## 2. 分类与侧边栏

### 2.1 模板类型
创建分类时可选 5 种模板：

| 模板 | 用途 |
| --- | --- |
| 小说类 | 自动生成编号章节目录（命名规则可自定义），适合诗集/小说/连载 |
| 学习 / 工作 / 生活 | 空白条目分类，自由记录笔记 |
| 关系类 | **思维导图**画布，用节点管理 Todo 及因果关系 |
| 自定义 | 空白分类 |

### 2.2 新建/管理分类
- 点击「**+ 添加分类**」或按 <kbd>Ctrl</kbd>+<kbd>N</kbd> 打开新建窗口，填名称、选模板、配置命名规则与初始数量后创建。
- 分类行右侧 `⋯` 菜单：**打开 / 重命名 / 删除**。
- **拖拽排序**：按住分类名（或章节名）左键拖到目标行，按落点位置排序上下级。

### 2.3 展开 / 折叠
- 点击分类前的箭头可展开/折叠目录；展开后可见「分类概览」与各章节条目。

## 3. 小说类 / 分类笔记

### 3.1 概览与滚动
- 进入分类后是卡片式概览，条目多时**可上下滚动**，离开/返回后滚动位置会被记住。

### 3.2 编辑一个条目
- 点击某篇进入编辑器：可改**标题**、写**正文**、加**标签**、勾选**完成**。
- 标签通过「**+**」按钮打开标签库（可搜索已有标签，也可直接输入回车新建）。
- 底部「上一首 / 下一首」在篇目间跳转。

### 3.3 文本输入快捷键
- <kbd>Ctrl</kbd>+<kbd>A</kbd>：全选当前文本框内容。
- <kbd>Ctrl</kbd>+<kbd>S</kbd>：保存当前文本（失焦提交）。

## 4. 思维导图（关系类）

### 4.1 画布基础
- 顶部可切换**思维导图 / 列表**视图。
- **添加节点**：点击右上「添加节点」，或双击画布空白处。
- **移动节点**：左键拖拽；移动结束位置自动保存。
- **编辑节点**：单击节点打开右侧「节点详情」面板。
- **删除节点**：在详情面板点「删除节点」，或选中后按 <kbd>Delete</kbd>/<kbd>Backspace</kbd>，两者都会弹确认。
- **插入图片**：节点内容、章节正文、日历笔记都支持 **Ctrl+V 粘贴图片**（自动存入 IndexedDB 并在正文插入引用），也可用「插图」按钮选文件；切换「预览」即可看到渲染出来的图片。

### 4.2 节点详情（Todo 项）
每个节点可填写：
- **标题 / 内容**：节点核心信息。
- **原因 / 导向 / 结果**：描述因果与去向（在画布上展示）。
- **标签**：与章节共用同一套标签。
- **解决方案**：内容+状态（●正在做 / ○暂停 / ✓已完成），以**绿色连线/节点**展示，可拖拽位置。
- **子任务**：把其它节点设为当前节点的子任务；也可展开/折叠子任务子树。

### 4.3 连线
- **左键手柄连线**：从节点底部圆点拖到目标节点。
- **右键拖线**：按住节点右键拖到其它节点松开——拖拽过程显示一条**直虚线**，松手后删除虚线并正式建立连线。
- **删除连线**：点击一根连线即可删除。
- 若已连过同一节点，会提示「**已经连接过此节点了！**」。

### 4.4 截止日期 / 长期任务
- 在节点详情可为节点设置**截止日期**，该任务会出现在日历对应日期（作为「截止任务」）。
- 点击「**设为长期**」后变为长期任务，无固定日期、不出现在日历。

## 5. 日历与日程

### 5.1 视图与导航
- 打开日历：点击侧边栏「日历」或按 <kbd>Ctrl</kbd>+<kbd>B</kbd>。
- 支持**月 / 周 / 日**视图切换，`< >` 与「今天」导航。

### 5.2 某一天的详情
点击某天，右侧面板可编辑：
- **今日笔记**：随手记录当天总结。
- **待办事项**：回车添加，勾选完成，悬停可删除。
- **事件安排**：时间 + 内容。
- **截止任务（思维图）**：显示思维图中绑定了当天为截止日期的节点，点击可跳回该节点。

### 5.3 日历标记脚本（进阶）
可编写脚本自动给日期块加标记（节日、打卡等）。详见 [`calendar-script-docs.md`](./calendar-script-docs.md) 或在「设置 → 管理日历标记脚本」里新建示例脚本。

## 6. 全局搜索

- 顶栏搜索框（或 <kbd>Ctrl</kbd>+<kbd>K</kbd>）打开全局搜索。
- 支持范围：**全部 / 当前分类 / 日历笔记 / Todo / 思维导图**。
- 命中内容高亮，点击结果自动跳转到对应位置。

## 7. 设置与个性化

打开「顶栏齿轮 → 设置」：

| 项 | 说明 |
| --- | --- |
| 默认视图 | 启动时进入工作台还是日历 |
| 主题 | 浅色 / 深色 / 跟随系统 |
| 字体大小 | 滑块调整全局基础字号（12–24px） |
| 快捷键 | 修改/重置「新建分类 / 打开日历 / 全局搜索」组合键 |
| 日历标记脚本 | 创建/编辑/启停日历标记脚本（见上文） |
| 配置文件 | 高级：直接编辑持久化 JSON 源文本（高风险） |
| 数据备份 | 导出/导入 JSON 备份 |

全局快捷键默认：<kbd>Ctrl</kbd>+<kbd>N</kbd> 新建、<kbd>Ctrl</kbd>+<kbd>B</kbd> 日历、<kbd>Ctrl</kbd>+<kbd>K</kbd> 搜索、按 <kbd>d</kbd> 切换主题。

## 8. 数据备份与异地迁移

- 所有数据保存在浏览器 **localStorage**（键 `my-omni-workspace`）；清除浏览器数据会丢失内容，**请定期备份**。
- 「设置 → 数据备份 → **导出 JSON**」下载一份归档；在其它浏览器/设备「**导入 JSON**」即可恢复（导入会覆盖现有数据，请先导出）。

## 9. 常见问题

- **标记脚本不生效？** 确认脚本已启用、写了 `renderDate(...)`；看浏览器控制台报错。
- **界面文字太小/太大？** 「设置 → 字体大小」滑块调整。
- **节点拖不动？** 左键按住拖动（移动范围跨节点时位置会自动保存）；右键是“连线”，不是移动。
- **找不到某个分类/节点？** 用顶栏全局搜索。
- **数据换设备？** 用「导出/导入 JSON」。
