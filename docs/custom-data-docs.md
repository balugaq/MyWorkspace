# 自定义数据文件（用户私用 · 只读）

> 本项目为纯前端静态站点（`output: "export"`），`public/` 下的文件会随构建原样拷贝到 `out/`，
> 应用运行时用同源 `fetch(...)` 只读加载。这些数据**不回写磁盘**、**不上传**，仅供本机使用。
> 文件缺失或加载失败时，页面顶部会 toast 提示「xxx 加载失败，已跳过」，日历照常展示。

---

## 1. 节日标记 `public/custom_festivals.yml`

### 1.1 Schema

```yaml
festivals:
  - name: "节日名称"          # 必填
    festival_rule: "5-2-7"    # 见下方规则说明，必填
    color: "#FF0000"          # 徽标颜色，默认 slateblue
    holiday_override: true    # true → 日格右上角显示橙底红字「假」，默认 false
    workday_override: false   # true → 日格右上角显示蓝底白字「班」，默认 false
```

### 1.2 festival_rule 支持的 4 种写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `MM-DD` | 每年固定公历月-日 | `11-27` = 每年 11 月 27 日 |
| `YYYY-MM-DD` | 仅该公历日期 | `2026-07-09` = 仅 2026-07-09 |
| `M-W-D` | 每年某月第 N 个星期几（**星期 1-7 = 周一~周日**，7=周日） | `5-2-7` = 5 月第 2 个周日（母亲节） |
| `L月-日` | 每年农历月-日（换算成公历展示） | `L8-15` = 农历八月十五（中秋） |

### 1.3 展示行为

- 命中节日的日期，日格内显示**彩色徽标**（名称，底色为 `color`）。
- `holiday_override` / `workday_override`：日格**右上角**加「假」（橙底红字）/「班」（蓝底白字）角标。可多个并存。
- 「假/班」仅为**视觉徽标**，不参与真正的调休/换位计算（本项目无调休系统）。

## 2. 通讯录 + 生日提醒 `public/address_book.yml`

### 2.1 Schema

```yaml
people:
  - name: "称呼"            # 必填
    description: "一句话简介"  # 可空
    birthday: "1995-06-15"   # 公历，或 "L1995-06-15" 表示农历（见 2.2），可空
    address: "地址"          # 可空
    roles: ["朋友", "同事"]   # 用户自填，表示此人身份，可空
    contact:                  # 联系方式，可空
      - type: phone
        value: "+1-555-1234"
      - type: qq
        value: "123456789"
      - type: email
        value: "x@example.com"
      - type: wechat
        value: "wx_id"
```

### 2.2 birthday 规则

- `YYYY-MM-DD`：公历生日。年份仅作展示，匹配只看**月日**。
- `L1995-06-15`：农历生日（`L` 前缀）。年份仅作展示，匹配时把“农历六月十五”换算成**当年**对应的公历日期。使用 `lunar-javascript` 库换算，支持闰月与大小月。
- 若某人过生日（公历或农历换算后命中当天）：
  - 日格**右上角**显示一个 🎂 徽标（多人同天也只显示一个）。
  - 日期详情右侧面板（DayDetail）顶部显示「今日生日」姓名列表。

## 3. 农历日期显示

- 日期详情（DayDetail）头部会显示所选日期的中文农历，如「农历五月小初一」「农历闰六月廿三」（含大小月）。仅展示，不参与匹配。

---

## 4. 常见问题

- **没生效？** 确认文件名在 `public/` 下、YAML 缩进正确；看浏览器控制台是否有 `GET /xxx.yml 404`。
- **改了文件要刷新才生效**：应用首次加载后缓存数据到内存，改 `public/*.yml` 后需刷新页面。
- **要编辑数据？** 本功能只读。直接修改 `public/` 下 YAML 文件（本机手动编辑），刷新页面即可看到效果。
